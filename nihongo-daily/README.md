# 日语小步走 · Nihongo Daily

一个面向中文零基础学习者的日语入门网页。每天花约 10 分钟，按顺序学习发音、常用表达和基础句型。

**在线体验：**[打开日语小步走](https://nihongo-daily-20261011.aglowbee2.chatgpt.site)

## 功能

- 30 节循序渐进的入门课程，每节约 10 分钟。
- 每课包含讲解、日语朗读入口和 3 道小测题。
- 小测答对至少 2 题即可完成课程，并解锁下一课；已完成课程可以随时复习。
- “今天”“课程表”“复习”三个学习入口，并显示完成进度和连续学习记录。
- 支持添加到手机主屏幕；访问过的静态资源会由 Service Worker 缓存，方便再次打开。
- 朗读功能使用设备浏览器自带的日语语音合成；是否有日语语音取决于设备和浏览器。

## 开始使用

无需安装依赖或构建工具。使用任意静态 HTTP 服务器打开项目根目录即可。例如：

```bash
python3 -m http.server 4173
```

然后在浏览器访问 <http://localhost:4173>。

也可以部署到任意静态网站托管服务，将项目根目录作为网站根目录。HTTPS 环境下可使用 PWA 安装和离线缓存功能；本地 `localhost` 也被浏览器视为安全环境。

## 运行测试

课程和进度逻辑的测试使用 Node.js 内置测试运行器，无需安装第三方包：

```bash
npm test
```

## 学习记录与隐私

学习进度保存在当前浏览器的 `localStorage` 中，不需要注册账号，也不会同步到其他设备或浏览器。清除该站点的浏览器数据会同时清除本机学习记录。应用使用浏览器原生语音合成，不会将输入内容发送到服务端。

## 项目结构

```text
index.html              页面入口
styles.css              响应式界面样式
app.js                  页面交互与导航
src/course.mjs          30 课课程内容和测验
src/speech.mjs          等待语音加载并选择日语语音
src/progress.mjs        解锁、评分和本地进度存取
manifest.webmanifest    PWA 配置
sw.js                   离线资源缓存
icon.svg                应用图标
tests/                  课程和进度逻辑测试
```

## 技术

原生 HTML、CSS 和 JavaScript ES 模块，无运行时第三方依赖。进度存储使用 Web Storage，朗读使用 Web Speech API。
